# Lab 01 — Localhost Web Server

## Objective
Create and test a local HTTP server using Python.

## Server
- Address: 127.0.0.1
- Port: 8000
- Server: Python HTTP Server

## Test
curl http://127.0.0.1:8000/

## Result
The local server successfully returned the HTML page.

## Security Concept
127.0.0.1 refers to the local machine. The server was intentionally bound to localhost for safe practice.
